# 🎮 Juegos Clásicos en C/C++

Este repositorio reúne implementaciones de juegos tradicionales desarrollados en C/C++ para ejecutarse en terminal/consola. El objetivo del proyecto es practicar la lógica de programación, el control de flujo y la manipulación de arreglos y matrices.

---

## 📝 Descripción Corta (para la sección *About* de GitHub)

> **Descripción:**  
> 🎮 Colección de juegos tradicionales (Ahorcado y Triqui) desarrollados en C/C++ para ejecución en consola y práctica de lógica de programación.

---

## 🎲 Juegos Incluidos

1. 🔤 **Ahorcado (`ahorcado.cpp`):** Juego interactivo de adivinanza de palabras por intentos limitados.
2. ❌⭕ **Triqui / Tres en Raya (`triqui.cpp`):** Juego de mesa para dos jugadores basado en una matriz de $3 \times 3$.

---

## 🛠️ Tecnologías Utilizadas

* **Lenguaje:** C++ / C
* **Entorno de Ejecución:** Terminal / Consola
* **Compilador Recomendado:** GCC / MinGW / Clang

---

## 🚀 Instalación y Ejecución

Sigue estos pasos para clonar, compilar y ejecutar cada juego en tu equipo:

### 1. Clonar el Repositorio

```bash
git clone https://github.com/JuanAnd-coder/Juegos-en-C.git
cd Juegos-en-C
```

---

### 2. Ejecutar el Juego: Ahorcado (`ahorcado.cpp`)

Para compilar y jugar al **Ahorcado**, ejecuta en tu terminal:

* **Compilar:**
  ```bash
  g++ ahorcado.cpp -o ahorcado
  ```
* **Ejecutar en Linux / macOS:**
  ```bash
  ./ahorcado
  ```
* **Ejecutar en Windows (PowerShell / CMD):**
  ```cmd
  .\ahorcado.exe
  ```

---

### 3. Ejecutar el Juego: Triqui / Tres en Raya (`triqui.cpp`)

Para compilar y jugar al **Triqui**, ejecuta en tu terminal:

* **Compilar:**
  ```bash
  g++ triqui.cpp -o triqui
  ```
* **Ejecutar en Linux / macOS:**
  ```bash
  ./triqui
  ```
* **Ejecutar en Windows (PowerShell / CMD):**
  ```cmd
  .\triqui.exe
  ```
